# Wishlist App

Pet-проект для погружения в Golang.
Приложение для создания и шаринга вишлистов, с возможностью резервации конкретного айтема.

## Сервисы

- auth-service - регистрация/логин + JWT
- user-profile-service - публичный профиль пользователя  
- wishlist-service - wishlist’ы и их айтемы 

## Технологии

- Go
- PostgreSQL  
- Kafka  
- JWT  
- Docker Compose  

## Запуск 
Сервисы запускать отдельно по инструкции в readme сервисов
